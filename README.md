# Student Academics Analysis Project

This repository contains a project analyzing student academic data to uncover insights and build predictive models. It includes data preprocessing, exploratory data analysis, and machine learning techniques to understand and forecast student performance.

## Features

- **Data Preprocessing**:
  - Handling missing values.
  - Transforming categorical and numerical data.
- **Exploratory Data Analysis (EDA)**:
  - Visualizations to explore distributions and trends.
  - Correlation analysis to identify relationships between features.
- **Predictive Modeling**:
  - Building a Random Forest Regressor for academic performance prediction.

## Visualizations

The project employs a variety of visualizations to better understand the data:
- Distribution histograms for grade percentages.
- Box plots and violin plots for category-wise analysis.
- Heatmaps for feature correlation.

## Machine Learning

A Random Forest Regressor is used for predictive modeling, with steps including:
1. Splitting the dataset into training and testing sets.
2. Encoding categorical features.
3. Evaluating model performance using Mean Squared Error (MSE).
